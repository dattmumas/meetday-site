Meet Day

A lifting log that judges every set like a meet.

Your trainer declares the loads. Each set gets three lights: reps, load and effort. A set without a red light is a good lift. After the session, a written rulebook sets the next loads: every set good and the load goes up, a red light and it holds.

The trainer can be you, or an AI assistant you connect with a personal API key. It reads your scoresheets, declares the next loads and writes the call for the day.

Blocks with a deload week, a weekly schedule, warm-ups planned in plates from the plates in your gym, a rest clock on the Lock Screen, and more than 600 exercises with instructions.
